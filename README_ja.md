## 概要

PicAutoClicker Free は、スクリーンショット上のターゲット画像をテンプレートマッチングで検索し、自動的にクリックを行う Windows 向けデスクトップアプリケーションです。

プログラミング不要で、GUI から直感的に操作できます。繰り返し作業の自動化・定型操作の省力化など幅広い用途に活用できます。

## インストール

1. [Releases ページ](https://github.com/terukilab/PicAutoClicker-Free/releases) から `PicAutoClicker_free.zip` をダウンロード
2. ZIP を任意のフォルダに解凍
3. `PicAutoClicker_free.exe` をダブルクリックして起動

インストーラーは不要です。解凍してすぐ使えます。  
アンインストールする場合は解凍フォルダごと削除してください。

## 機能

- 画面キャプチャで画像を登録（ドラッグで切り抜くだけ）
- テンプレートマッチングによる画像検索
- 複数プロジェクトをタブで管理
- ループ実行（指定回数を繰り返す）
- ステップ間待機・クリック前待機の設定
- タイムアウト設定（画像が見つからない場合にスキップ、0 で無限待機）
- 認識率 (Confidence) のスライダー調整
- ウィンドウ指定検索（特定ウィンドウ内のみを検索対象に絞り込み）
- ドラッグ＆ドロップで実行順の変更
- リアルタイム実行ログ
- ESC / マウス操作による緊急停止
- 日本語 / English 表示切り替え

## 使い方

### 基本的な流れ

1. `[＋]` ボタンで新しいプロジェクトタブを作成する
2. `✂ 画像取得` ボタンをクリックし、クリックしたい場所をドラッグして切り抜く（複数登録可能）
3. 左パネルで実行設定を調整する
4. `▶ 再生` ボタンで開始する

### 実行設定

| 設定項目 | 内容 |
|----------|------|
| ループ回数 | 画像リストを何周繰り返すか |
| ステップ間待機 | 各クリック後の待ち時間（秒） |
| クリック前待機 | クリック直前の待ち時間（秒） |
| タイムアウト | 画像が見つからない場合にスキップするまでの秒数（0 で無限） |
| 認識率 | マッチング閾値（値を下げると見つかりやすくなるが誤検知が増える） |
| 対象画面 | フルスクリーン / ウィンドウ指定 |
| 停止方法 | ESC キーのみ / マウス・キー操作 |

### 画像リストの操作

| 操作 | 方法 |
|------|------|
| 順番変更 | ドラッグ＆ドロップ |
| 削除 | 🗑 ボタン |
| 画像の差し替え | 右クリック → 画像を差し替える |
| コピー / ペースト | 右クリック → コピー / ペースト |
| 途中から再生 | 右クリック → この画像から再生 |

### プロジェクトタブの操作

| 操作 | 方法 |
|------|------|
| タブ追加 | `[＋]` ボタン |
| タブ名の変更 | タブを右クリック → 名前を変更 |
| タブの複製 | タブを右クリック → 複製 |
| タブの削除 | タブを右クリック → 削除 |

## 画像認識について

テンプレートマッチング (OpenCV) を使用しています。

- キャプチャ時と同じ解像度・色調で画面が表示されている必要があります
- 認識率を下げると見つかりやすくなりますが、誤検知が増えます
- ウィンドウ指定モードでは、特定アプリのウィンドウ内だけを検索対象にできます

---

## フェイルセーフ

マウスカーソルを画面の四隅に移動すると、自動操作を強制終了します。  
予期せぬクリックが続く場合はマウスを素早く画面端へ移動してください。
