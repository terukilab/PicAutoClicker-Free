# PicAutoClicker (Free版)

画像認識を活用した、直感的で使いやすい自動クリック・マクロツールです。
画面上の指定した画像を自動で探し出し、クリックやキー操作などのアクションを自動実行します。

## 🌟 特徴

- **画像認識ベースの自動化:** 座標を指定するだけでなく、「この画像が画面に表示されたらクリックする」といった柔軟なマクロが組めます。
- **直感的なUI:** プログラミングの知識は一切不要。画面を見ながら画像を切り抜き、アクションを選ぶだけで自動化が完成します。
- **複数アクションの連続実行:** 複数のステップを順番に実行するシーケンスを簡単に作成できます。

## 📥 ダウンロードとインストール

1. 画面右側の **[Releases]** から最新バージョンのページを開きます。
2. `PicAutoClicker_free.zip` をダウンロードします。
3. ダウンロードしたZIPファイルを、パソコンの好きな場所（デスクトップなど）に展開（解凍）してください。
4. フォルダ内にある `PicAutoClicker_free.exe` をダブルクリックすると起動します。
   （※インストール不要、ポータブルに動作します）

## 🚀 簡単な使い方

1. **ツールの起動:** `PicAutoClicker_free.exe` を起動します。
2. **画像の登録:** 画面上のクリックしたいボタンやアイコンを、ツールの「切り抜き（Snipping）」機能でキャプチャします。
3. **アクションの設定:** キャプチャした画像が見つかった時の動作（左クリック、右クリック、キー入力など）を設定します。
4. **実行:** 「実行（Run）」ボタンを押すと、ツールが画面を監視し、画像が見つかり次第自動でアクションを実行します。
